# 13F583N012 电机协议分析

本仓库为 **13F583N012** 电机的通信协议分析

13F583N012 为 **36V** 版本。若购买时间较早，可能收到的是 **32.4V** 版本（**13F583N011**）。据反馈，13F583N011 可能无法通过 13F583N012 的协议启动

由于我目前没有 13F583N011 的样本，暂时无法对其进行分析，后续若有机会，会进行补充.

---

## 注意事项

1. **安全第一**：该电机满功率转速可达上万转，请注意防止机械伤人
2. **供电要求**：驱动时，串口端子（`4pin`）需要提供 `3.3V` 供电，电机才能启动
3. **电源要求**：请使用合适功率的电源进行驱动,电源需要一些余量,否则可能无法使电机达到最高功率
