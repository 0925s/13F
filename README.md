# 13F583N012 电机协议分析

本仓库为 **13F583N012** 电机的通信协议分析

13F583N012 为 **36V** 版本。若购买时间较早，可能收到的是 **32.4V** 版本（**13F583N011**），两者协议似乎是通用的

---

## 注意事项

1. **安全第一**：该电机转速可达上万转，请注意防止机械伤人
2. **供电要求**：驱动时，串口端子（`4pin`）需要提供 `3.3V` 供电，电机才能启动，具体接线见 `通讯协议解析.docx`
3. **电源要求**：请使用功率合适的电源进行驱动,电源需要一些余量,否则可能无法使电机达到最高功率
